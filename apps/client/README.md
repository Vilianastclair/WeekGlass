# WeekGlass client

The Flutter app shares its calendar, sync and update workflows across Windows and Android. The native runners in `windows` and `android` provide platform integrations.

For the Flutter version, platform tools and build commands, see [Build from source](../../README-EN.md#build-from-source). For the Windows EXE, see [Build the Windows x64 installer](../../tooling/windows-installer/README.md).
