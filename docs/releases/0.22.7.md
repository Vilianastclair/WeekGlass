# WeekGlass 0.22.7

Windows x64 版，构建号 56。

- WeekGlass 自带的窗口动效默认关闭，沿用 Windows 的窗口行为。
- 如需开启，在设置的「皮肤与外观」中选择「轻柔」或「液态玻璃」。已选模式保留，应用内的玻璃动效设置独立。

## English

Windows x64, build 56. WeekGlass window effects are off by default. Choose Gentle or Liquid Glass under Appearance to turn them on. Existing preferences and in-app glass effects are unchanged.
