## 只看清醒时段

在「设置 → 日历与外观」开启「睡眠时段」，并选择睡觉和起床时间。日历隐藏清醒区间之外的日程，跨过边界的日程只显示落在清醒区间内的部分。日程的实际起止时间不变，关掉这项设置就能看到完整日历。

## 跨设备同步作息

同一账号允许作息同步后，两端会共享睡眠时段开关、睡觉时间和起床时间。从已启用日程同步的旧版升级时，在「设置 → 云服务」开启作息同步；不启用也能继续同步日程。两端同时改出不同作息时，按提示选择保留本机或云端设置。连接旧版自托管服务器时，日程仍可同步，作息继续保存在本机。

## 从网页文件导入课表

北京大学选课网、华中科技大学微校园和中山大学学生课表支持通过历史 HTML 格式导入。先在浏览器里打开已经显示课程的个人课表，另存为 UTF-8 编码的 HTML 或 HTM。然后在 WeekGlass 的学校课表导入中选择对应格式和文件，核对预览、学期和节次后导入。

应用在本机读取文件，不会执行网页脚本或登录上述学校的教务系统。武汉大学在线导入沿用原入口。历史格式并不覆盖各校所有新版页面，首次导入请对照原课表核对。[查看支持的页面和完整导入步骤](../product/school-import-adapters.md)。

已在用 WakeUp 课程表时，可在 WakeUp [导出日历文件](https://www.wakeup.fun/doc/export_schedule.html)，再从 WeekGlass 的「导入日程」选择该 ICS 文件，不需要重新登录学校。
