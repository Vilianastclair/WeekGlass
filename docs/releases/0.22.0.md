# WeekGlass 0.22.0

打开「学校课表」，选择学校和学期，在学校的教务页面登录，打开本人课表后点「读取课表」。Windows 与 Android 现在使用同一套本机解析器，不用另外安装 WakeUp 或 Java，也不用把网页保存为文件。武汉大学仍走原来的专用入口。

学校如果有独立的研究生教务，请选对应入口。没有预置网址的学校可以填写校方公布的 HTTPS 教务地址；没有注明教学周数的页面，按提示填写实际周数。核对课程、第一教学周和节次时间后再保存。

本版接入 WakeUp 公开归档中的全部 83 个解析器类。学校是否能直接导入仍取决于当前教务页面和本人登录权限；学校名单不等于逐校实测。见[支持范围与实测结果](../qa/school-adapters-20261118/portal-integration.md)。
