# WeekGlass 0.22.10

Windows x64 版，构建号 59。

- 周表 PDF 使用 A4 单页黑白版式，打印时保留完整一周，不再显示角落标签。
- 学校教务课表、课表图片和文字导入直接使用软件校验后的排程。来源缺少学期日期、总周数或节次时刻时，可在导入时设置。

已安装 WeekGlass 的用户可在「设置 → 软件与通知」检查更新。

## English

Windows x64, build 59.

- Print a full week on one monochrome A4 sheet, without corner labels.
- Import timetables from school portals, images, or text after WeekGlass validates the schedule. Set the term start, number of weeks, or class times when the source leaves them out.

Check for updates under Settings → Software and notifications.
