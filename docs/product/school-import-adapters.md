## 从教务网页文件导入

1. 在浏览器打开已经显示课程的个人课表页面，另存为 UTF-8 编码的 HTML 或 HTM。只有保存后包含实际课程数据的网页才可读取；登录页、空白动态页、PDF 和 MHTML 不适用。
2. 在 WeekGlass 打开「导入学校课表」，选「从教务网页文件导入」，确认学期和页面格式，选择不超过 4 MB 的本地文件。Android 也可选择已保存的文件。
3. 核对课程，选择第一教学周的周一，并按校区作息填写教学节次。应用按文件里的星期、节次和教学周预览，保存前执行去重。没有明确时间的课程会列在未自动安排的内容，请对照原表。

同一格式和学期重复导入会复用已确认的日期、时刻及假期设置，再次确认后才写入。手动调整过的课程保持不变；文件未包含的旧课程不会作为教务已取消的课程批量移除。可撤销整次写入。

## 登录与数据边界

- 武汉大学使用 `jwgl.whu.edu.cn` 和 `cas.whu.edu.cn`。仅允许精确匹配的 HTTPS 教务和认证主机，使用 443 端口，网址中不得包含账号凭据。
- 密码、验证码和 Cookie 保留在学校页面。应用只在教务来源读取固定的个人课表响应。学校查询需要验证码时，由用户在学校页面完成。
- 新导入使用 `whu:` 来源标识。历史 `shu:` 和 `buct:` 来源仍可识别，已有日程保留在日历中。
- 网页文件仅在设备上读取，不运行其中的脚本，不访问链接或读取登录信息。保存的课程分别使用 `pku_html:`、`hust_html:`、`sysu_html:`，不会修改武汉大学登录状态或教学周设置。

## 假期

默认“照常导入”，不猜测学校假期。用户按学校通知添加一个或多个名称及起止日期，包含首尾两天；范围可修改或删除，按学校和学期保存。

“照常导入”显示范围内课程数和总节数；“排除假期”显示排除与保留节数，重叠的日期范围只计算一次。改变范围或模式需重新勾选确认。补课日期仍按教务返回的星期、节次和周次，不自动将假期课程挪到周末。

选择排除假期默认只跳过本次课程，已导入的旧课程保留。另行勾选“同时移除已导入且未调整的 X 条课程”并再次确认，才清理相同来源的旧课程；提示明确说明整次导入可撤销。此清理勾选不跨会话记忆，候选课程变化时失效。手动改过名称、时间或备注的课程仍受保护；其他未选课程和手工日程不因此移除。普通空课表仍不会清空旧日历。清理后可立即撤销；以后想恢复，使用原有“重新加入我曾删除的课程”选项。日程没有变化时仍可保存导入设置。

## 验证

自动化测试覆盖武汉大学匿名样本中的 152 次课、历史来源兼容、假期范围与补课、手改保护，以及三种本地格式的单双周、单周单节、跨行布局和失效页面。手机尺寸的文件导入测试覆盖选择、设置节次、写入、去重和撤销。
