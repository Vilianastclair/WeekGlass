# 从学校教务导入课表

在「学校课表」中选择学校，在校方页面登录，打开**本人、本学期**的课表，再让 WeekGlass 读取。课表显示在预览里，核对教学周与节次时间后保存。无需安装 WakeUp，也无需保存网页。

## 选择学校

武汉大学沿用已通过学生账号验收的专用流程，包括校方的查询验证码。其匿名回归样本含 8 门课、17 条上课规则、152 次日程。

其他学校可按校名或域名搜索。本科和研究生系统不同的学校，请选择对应入口。没有预置网址时，填入学校公布的 HTTPS 教务入口；青果教务可打开本人「正选结果」页。周次和节次以校方页面为准。

两端使用同一套 [本机解析器](wakeup-engine-runtime.md)。[注册表](../../tooling/course_adapter_engine/registry.json) 来自公开归档，收录全部 83 个解析类；旧正方有两个模式，合计 84 种。其中 1 种是 CSV 文件格式，并非教务登录方式。[选校目录](../../tooling/scripts/build_wakeup_bindings.py) 将有来源依据的校名和系统对应到解析器；没有适配器的学校，不会因为找到了网址就标为已接入。选校无需上传搜索词。

学校更换系统、只开放校园网，或者登录后必须通过独立接口才能取得个人课表，都会影响实际可用性。目录中来自旧资料的 HTTP 地址只尝试同一校方主机的 HTTPS，绝不退回明文登录。学校网址已变更时，请用学校现在公布的安全入口。WakeUp 官网的覆盖数字不等于 WeekGlass 的实测校数。

## 确认后才保存课程

课程名称、周次、星期、节次、地点和教师从打开的教务页面读取，在本机转换为预览。核对第一教学周的周一与本校上下课时间；没有明确时间的项目不应直接排进日历。原先已保存的课程照常显示，撤掉旧的网页文件入口不会删除任何日程。

学校账号、密码和验证码仅在学校页面填写。WeekGlass 云账号与学校账号无关。开启日程同步后，已保存的课程可作为日程同步；学校登录信息、Cookie 和教务原网页不上传到 WeekGlass 云。

## 已核对的教务页面

在隔离的 Edge 中运行应用实际随包分发的读取脚本，使用 [WakeUp 作者保存的教务页面](https://github.com/YZune/Schedule_Html)。厦门理工学院样本读出 11 条上课规则，展开为 133 次日程；山东政法学院样本为 6 条、56 次；海南大学样本为 23 条、159 次。三份页面都没有提供每节课的起止钟点，首次使用时需按本校作息表确认。这里检验的是教务网页到日历的转换，不是这些高校今天的账号登录状态。

## 假期

默认“照常导入”，不猜测学校假期。用户按学校通知添加一个或多个名称及起止日期，包含首尾两天；范围可修改或删除，按学校和学期保存。

“照常导入”显示范围内课程数和总节数；“排除假期”显示排除与保留节数，重叠的日期范围只计算一次。改变范围或模式需重新勾选确认。补课日期仍按教务返回的星期、节次和周次，不自动将假期课程挪到周末。

选择排除假期默认只跳过本次课程，已导入的旧课程保留。另行勾选“同时移除已导入且未调整的 X 条课程”并再次确认，才清理相同来源的旧课程；提示明确说明整次导入可撤销。此清理勾选不跨会话记忆，候选课程变化时失效。手动改过名称、时间或备注的课程仍受保护；其他未选课程和手工日程不因此移除。普通空课表仍不会清空旧日历。清理后可立即撤销；以后想恢复，使用原有“重新加入我曾删除的课程”选项。日程没有变化时仍可保存导入设置。
